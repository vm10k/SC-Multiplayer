## 🌟 Key Features & Updates

* ⚔️ **Live 8-Player Multiplayer**: Host and join active online skirmishes up to 8-player lobbies with low-latency WebSocket command synchronization.
* 📈 **Expanded 100-Unit Cap**: Army limits increased to 100 active units on-field for massive, cinematic engagements.
* ⚡ **Optimized RTS Netcode**: High-tick packet sync handles unit pathfinding, fog of war, projectiles, and spellcasting without desync.
* 📜 **Full Campaign & Custom Scenarios**: Play scripted story missions, Tower Defense, Protect Athena, and HunterXHunter skirmish maps.
* 🛸 **Complete Tri-Faction Arsenal**: Fully realized Terran, Zerg, and Protoss rosters—complete with tech trees, Zerg creep mechanics, cloaking, and special abilities.
* 📹 **Built-In Replay Engine**: Save and review past multiplayer games and single-player runs to analyze strategies and build orders.
* 📱 **Mobile & Desktop Cross-Play**: Play seamlessly on desktop with classic hotkeys or on mobile devices via an intuitive multi-touch gesture system.

## 🕹️ Controls & Navigation

### 💻 Desktop (Keyboard & Mouse)
| Action | Input |
| :--- | :--- |
| **Select Unit / Building** | `Left Click` |
| **Move / Attack-Move / Gather** | `Right Click` |
| **Select All Units of Type** | `Double Left Click` |
| **Band-Box Multi-Select** | `Click + Drag` box across units |
| **Camera Pan** | Move cursor to screen edge or `Arrow Keys` |
| **Control Groups** | `Ctrl + 1-9` to create • `1-9` to jump to group |

### 📱 Mobile Touch & Gesture System
| Action | Touch Gesture |
| :--- | :--- |
| **Select / Deselect** | `Tap Once` on unit or building |
| **Select All Same Units** | `Double Tap` on the unit |
| **Set Destination / Attack** | `Hold Press` on the ground or target |
| **Box Multi-Select** | `Two-Finger Press + Drag` across units |
| **Pan Map** | `Slide Finger` across screen |
